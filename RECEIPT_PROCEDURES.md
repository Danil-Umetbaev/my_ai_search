

### Шаг 7 — функциональная проверка приложения, 10.11.2026

Проверено через работающий API: повторные сообщения и подтверждения заявки (по пять одновременных отправок), одна заявка и одно событие создания, права доступа, устаревшие кнопки, новое обращение, завершение без заявки. Пять одновременно работающих пользователей имеют отдельные истории; чужая сессия недоступна. В заявке проверены факты, результат, пройденные процедуры, исправления, источники и диалог.

В отдельном процессе ASGI с настоящей БД и временными пользователями проверены загрузка моделей, искусственный сбой поиска, сохранение фактов и успешный повтор после восстановления. Рабочий процесс при этом не изменялся.

В браузере через nginx пройдены кнопки, свободный ввод, обновление страницы, новое обращение, подтверждение заявки, её карточка, завершение без заявки. При остановленном backend сообщение сохранилось; после запуска и обновления страницы кнопка повторной отправки доставила его один раз. Идентификатор кнопки при повторе дополнительно проверен отдельно.

Повторить функциональную проверку: скопировать backend/tests/support_app_check.py в app:/tmp/support_app_check.py, выполнить docker compose exec -T -e PYTHONPATH=/backend app python /tmp/support_app_check.py. Скрипт удаляет созданные им учётные записи, сессии и заявки.

Ограничение: нагрузочная скорость исключена из приёмки по решению пользователя. Проверка изоляции выполнялась непосредственно через API, браузерная — через nginx; лимит nginx 60 запросов/мин на адрес остаётся. p95 для пяти пользователей не подтверждён.
