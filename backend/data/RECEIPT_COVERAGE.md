# Покрытие базы: печать чеков

Дата аудита: 09.11.2026. Область: активная база `customer_knowledge`, 196 документов: 76 разделов АТОЛ, 73 страницы Пирит, 47 статей Вики. Проверены 27 сочетаний (3 семейства × 9 симптомов). Это карта знаний для проектирования процедур, а не доказательство качества RAG и не инструкция сотруднику к выполнению всех перечисленных операций.

## Как проверено и где границы

Чтение выполнялось напрямую из `documents`, без ранжирования RAG и без генерации ответов. Проверены каталог, полнотекстовые совпадения по симптомам и связанные разделы руководств. Использовались группы слов: бумага/лента/рулон/датчик, печать/промотка/не отвечает, пустой/белый, яркость/полосы/точки, замятие/заедание/перекос, QR/штрихкод, связь/COM/USB, ошибка/блокировка. Отсутствие прямой процедуры фиксируется в пределах активного текстового корпуса, не всего сайта и не всех возможных изображений.

Локальные PDF доступны; визуально сверены Пирит стр.9 и АТОЛ стр.27: изображения установки есть и дополняют текст. Все изображения корпуса целиком не распознавались. Скриншоты утилит, внешние архивы и отсутствующие гиперссылки отмечены как отдельные зависимости. Интернет-база в ходе этого аудита не обновлялась.

«Что можно сделать» — действия, поддержанные источником; граница «кассир/специалист» ниже является предлагаемой политикой продукта и требует согласования с заказчиком. Наличие текста ремонта не означает разрешение кассиру его выполнять. «Пробел» может означать недостающую процедуру, предусловие, материал или подробность, а не отсутствие любой информации.

Вики Принт — семейство, точная модель клиента пока не задана. Статьи про 80 или 57 Плюс Ф нельзя автоматически распространять на всё семейство. АТОЛ — руководство для платформы 5.0; Пирит — загруженная редакция локального PDF. Фактические версии оборудования клиента ещё нужно сверить.

## Главные находки

- **Пирит, бумага есть, ошибки нет:** в базе есть следующий диагностический шаг — печать диагностического отчёта (P2), а не только справка об индикаторах. Предыдущую эскалацию нельзя считать доказательством отсутствия знаний.
- **Вики, печати нет:** V1/V2 содержат проверки запрета печати и подключения; их нужно отделить от ремонта плат и прошивки. Фильтрация всей статьи по слову «плата» теряет полезные шаги.
- **АТОЛ, замятие:** A1 содержит отдельную последовательность, её нельзя смешивать с установкой рулона и перекосом.
- **Вики, QR:** специальная инструкция есть, но комплект в индексе неполный — отсутствует идентификация макроса.
- **Вики, установка рулона:** нынешний быстрый ответ является проверкой наличия бумаги; полноценной модельной инструкции замены в загруженных статьях нет.
- **Пустой чек:** прямых пользовательских процедур с этим названием в корпусе нет. Есть связанные проверки и сервисные материалы; нельзя выдавать их как доказанный диагноз.

## Матрица случаев

### АТОЛ FPrint-22ПТК

#### A-01 — Бумага закончилась

- **Случай:** АТОЛ FPrint-22ПТК; Бумага закончилась. Условия устанавливаются вопросами ниже.
- **Источник:** [A1](#source-a1), [A3](#source-a3)
- **Что известно:** Есть отдельные варианты для 80/58 мм и горизонтальной/вертикальной установки. Для 58 мм нужен ограничитель и настройка ширины.
- **Что можно сделать:** Открыть крышку, установить рулон по подходящей схеме, вывести конец, закрыть, проверить промотку. Сохранить запреты открывать во время печати и вытягивать бумагу при закрытой крышке.
- **Что нужно уточнить:** Ширина ленты; положение устройства; наличие ограничителя; доступ к настройке ширины.
- **Пробелы:** Рисунки 9–12 содержат номера деталей: текст без схем неудобен. Комбинацию вертикального положения и 58 мм нельзя выдавать простым склеиванием двух списков без проверки процедуры.
- **Ожидаемый исход:** Уточнение → инструкция; настройка драйвера при необходимости с помощью специалиста.

#### A-02 — Рулон установлен, ошибка «Нет бумаги»

- **Случай:** АТОЛ FPrint-22ПТК; Рулон установлен, ошибка «Нет бумаги». Условия устанавливаются вопросами ниже.
- **Источник:** [A2](#source-a2), [A1](#source-a1)
- **Что известно:** Раздел неполадок различает закончившуюся бумагу и неисправность датчика.
- **Что можно сделать:** Сопоставить установку рулона с A1. В источнике предлагается проверка датчика, при неполадке — сервис. Это не инструкция по ремонту датчика сотрудником.
- **Что нужно уточнить:** Точный текст; установлен ли рулон и правильно ли выведен конец; индикаторы; появилось ли после замены.
- **Пробелы:** Нет пошаговой проверки датчика без разборки и критериев её результата. Нельзя утверждать неисправность датчика только по сообщению.
- **Ожидаемый исход:** Уточнение/проверка установки → специалист при сохранении ошибки.

#### A-03 — Бумага совсем не выходит

- **Случай:** АТОЛ FPrint-22ПТК; Бумага совсем не выходит. Условия устанавливаются вопросами ниже.
- **Источник:** [A2](#source-a2), [A1](#source-a1)
- **Что известно:** Для отсутствия реакции на кнопку указаны текущая операция, замятие, поломка; для отсутствия ответа ПК — питание и кабель.
- **Что можно сделать:** Если выполняется команда — дождаться её окончания. При подтверждённом замятии использовать A1. Проверить промотку по A1 после корректной установки.
- **Что нужно уточнить:** Работает ли промотка; есть ли бумага; слышен ли механизм; выполняется ли команда; есть ли ошибка; реагирует ли на ПК.
- **Пробелы:** Один симптом не выбирает причину. Нет единой готовой процедуры для всех вариантов; сервисную часть нельзя превращать в пользовательские шаги.
- **Ожидаемый исход:** Уточнение → подходящая проверка; неустранённая аппаратная проблема → специалист.

#### A-04 — Выходит пустой чек

- **Случай:** АТОЛ FPrint-22ПТК; Выходит пустой чек. Условия устанавливаются вопросами ниже.
- **Источник:** [A1](#source-a1), [A2](#source-a2)
- **Что известно:** A1 задаёт направление термослоя; A2 содержит причины «Отсутствует печать»: головка, прижим, недостаточная яркость.
- **Что можно сделать:** Сверить тип и направление ленты с A1. A2 предписывает увеличение яркости при её недостаточности, аппаратные причины передаёт в сервис.
- **Что нужно уточнить:** Совсем пустой или бледный; началось ли после смены рулона; направление ленты; есть ли доступ к драйверу.
- **Пробелы:** Буквальная процедура «пустой чек» не найдена. Нет проверенного в этих разделах пути и значения настройки яркости. Причины из A2 — альтернативы, не установленный диагноз.
- **Ожидаемый исход:** Уточнение → проверка установки; настройка/ремонт при недостаточных данных → специалист.

#### A-05 — Бледная или частичная печать

- **Случай:** АТОЛ FPrint-22ПТК; Бледная или частичная печать. Условия устанавливаются вопросами ниже.
- **Источник:** [A2](#source-a2), [A3](#source-a3)
- **Что известно:** Пропуск точек связан в руководстве с печатающей головкой; низкая яркость — отдельная причина. Для 58 мм неверная ширина обрезает строку (A1/A3).
- **Что можно сделать:** Разделить пропуск точек, слабую печать и обрезанную строку. Сверить ширину в драйвере; при пропусках точек источник рекомендует сервис.
- **Что нужно уточнить:** Вся строка бледная, полосы или обрезан край; ширина рулона и настройка; перегрев; когда началось.
- **Пробелы:** Нет полного пользовательского пути изменения яркости в выбранных разделах. Нельзя использовать увеличение яркости для перегрева: там A2 рекомендует охлаждение и снижение яркости.
- **Ожидаемый исход:** Уточнение → настройка ширины при подтверждённом несоответствии; сервис для головки/неясного дефекта.

#### A-06 — Бумага замялась

- **Случай:** АТОЛ FPrint-22ПТК; Бумага замялась. Условия устанавливаются вопросами ниже.
- **Источник:** [A1](#source-a1), [A2](#source-a2)
- **Что известно:** Есть отдельные последовательности для заедания и перекоса ленты.
- **Что можно сделать:** При заедании: открыть крышку, освободить от смятых кусочков, обрезать конец, заправить по соответствующему варианту. При перекосе — вернуть ленту в штатное положение.
- **Что нужно уточнить:** Замятие или перекос; завершена ли печать; ширина и положение устройства; повторяется ли проблема.
- **Пробелы:** Сохранить запреты из A1. Глубокая разборка, заклинивший отрезчик и повторное замятие этим разделом не покрываются.
- **Ожидаемый исход:** Уточнение → инструкция для доступного замятия; недоступный механизм → специалист.

#### A-07 — Не печатается QR-код

- **Случай:** АТОЛ FPrint-22ПТК; Не печатается QR-код. Условия устанавливаются вопросами ниже.
- **Источник:** [A6](#source-a6)
- **Что известно:** Есть описание содержимого QR и примеры реквизитов, но это не устранение отсутствия QR.
- **Что можно сделать:** Объяснить назначение QR; собрать условия и передать проблему. Не применять макрос Вики.
- **Что нужно уточнить:** QR отсутствует целиком или не читается; вид документа; остальной текст печатается; версия ПО/шаблона.
- **Пробелы:** В активном тексте не найдена процедура восстановления QR для АТОЛ. Нужна инструкция производителя по конкретной версии/шаблону.
- **Ожидаемый исход:** Справка при необходимости → специалист.

#### A-08 — Касса не отвечает программе

- **Случай:** АТОЛ FPrint-22ПТК; Касса не отвечает программе. Условия устанавливаются вопросами ниже.
- **Источник:** [A2](#source-a2), [A4](#source-a4), [A5](#source-a5)
- **Что известно:** Есть проверка питания/кабеля и проверка связи через тест драйвера v.10; описан поиск портов.
- **Что можно сделать:** Проверить включение и подключение. При доступе к утилите: свойства → модель/канал → проверка связи; использовать поиск оборудования и выбрать найденное устройство.
- **Что нужно уточнить:** Программа/ОС; интерфейс; модель драйвера; ошибка; видит ли устройство тест драйвера; доступ к настройкам.
- **Пробелы:** Нет инструкции для каждой кассовой программы клиента. Wi-Fi зависит от установленного модуля; нельзя подставлять выдуманные IP/порт.
- **Ожидаемый исход:** Уточнение → проверка связи; драйвер видит, программа нет → специалист по интеграции.

#### A-09 — Конкретный код или текст ошибки

- **Случай:** АТОЛ FPrint-22ПТК; Конкретный код или текст ошибки. Условия устанавливаются вопросами ниже.
- **Источник:** [A2](#source-a2)
- **Что известно:** Есть разбор «Смена превысила 24 часа», «Нет бумаги», перегрева головки, прерванного закрытия смены, проблем ФН/ОФД и других сообщений.
- **Что можно сделать:** Только по точному совпадению и условиям: например, при перегреве дождаться охлаждения; при отсутствии бумаги — A1. Операции со сменой, ФН и регистрацией вынести на согласование специалисту.
- **Что нужно уточнить:** Полный текст/код; в какой программе и операции; индикаторы; версия; что уже делали.
- **Пробелы:** Нет универсальной полной таблицы всех числовых кодов драйвера/ПО. Неизвестный код не сопоставлять по похожим цифрам.
- **Ожидаемый исход:** Уточнение → справка и применимая процедура для известного сообщения; неизвестное/сервисное → специалист.

- **Пробелы:** Пошаговой процедуры удаления замятия и работы с отрезчиком в активном тексте нет. Общая фраза не разрешает извлекать детали или разбирать механизм.
- **Ожидаемый исход:** Уточнение → специалист для самого устранения замятия; установка нового рулона отдельно по P1.

#### P-07 — Не печатается QR-код

- **Что известно:** Есть только общий путь диагностического отчёта; отдельной текстовой процедуры QR в руководстве не обнаружено.
- **Что можно сделать:** Собрать вид документа, пример дефекта и версию; при необходимости получить диагностические сведения.
- **Что нужно уточнить:** QR отсутствует или не читается; какой документ; печатается ли остальной текст; версия ПО.
- **Пробелы:** Нет применимой QR-инструкции и файла/настройки для Пирит. Возможное изображение QR в образце чека не является инструкцией восстановления.
- **Ожидаемый исход:** Уточнение → специалист; не применять процедуру Вики.

#### P-08 — Касса не отвечает программе

- **Случай:** Пирит 2Ф; Касса не отвечает программе. Условия устанавливаются вопросами ниже.
- **Источник:** [P5](#source-p5), [P11](#source-p11), [P12](#source-p12), [P13](#source-p13)
- **Что известно:** Разделы 9–10 описывают питание, кабель, ComProxy, Fito 2.3.2+, выбор COMZ, проверку статуса и повторную проверку настроек при отсутствии связи.
- **Что можно сделать:** Проверить питание и интерфейс; при имеющейся настройке выбрать правильный порт в Fito и запросить статус.
- **Что нужно уточнить:** Windows или другая ОС; COM/USB; установлен ли ComProxy; фактические COMX/COMY/COMZ; ошибка/статус; доступ администратора.
- **Пробелы:** Установка/удаление службы требует прав и дистрибутива; номер COM11 в примере нельзя считать фактическим. Другая ОС/кассовая программа не покрыта этими шагами.
- **Ожидаемый исход:** Уточнение → проверка связи; переустановка службы/неизвестная конфигурация → специалист.

#### P-09 — Конкретный код или текст ошибки

- **Случай:** Пирит 2Ф; Конкретный код или текст ошибки. Условия устанавливаются вопросами ниже.
- **Источник:** [P3](#source-p3), [P2](#source-p2), [P4](#source-p4)
- **Что известно:** Стр.65–66 перечисляют сообщения диагностики: батарея, авторизация, ОЗУ, модуль/связь ФН, регистрация, закрытый ФН, расхождение смен. Стр.64 описывает условия блокировки.
- **Что можно сделать:** Объяснить точное сообщение, собрать диагностический отчёт и передать специалисту согласно руководству.
- **Что нужно уточнить:** Точный текст; чек диагностики или кассовая программа; операция; статус/последний код; версия ПО.

### Вики Принт

#### V-01 — Бумага закончилась

- **Случай:** Вики Принт; Бумага закончилась. Условия устанавливаются вопросами ниже.
- **Источник:** [V1](#source-v1)
- **Что известно:** Статья связывает красный индикатор с датчиком бумаги и предлагает убедиться в наличии бумаги в отсеке.
- **Что можно сделать:** Проверить наличие бумаги. Для самостоятельной замены нужен мануал конкретной модели, которого эта статья не заменяет.
- **Что нужно уточнить:** Точная модель 57/57 Плюс/80/80 Плюс и ревизия; есть ли рулон; индикатор.
- **Пробелы:** В загруженных статьях нет полноценной процедуры установки рулона с направлением и подходящей лентой для каждой модели.
- **Ожидаемый исход:** Короткая проверка/уточнение → специалист или модельная инструкция после пополнения базы.

#### V-02 — Рулон установлен, ошибка «Нет бумаги»

- **Случай:** Вики Принт; Рулон установлен, ошибка «Нет бумаги». Условия устанавливаются вопросами ниже.
- **Источник:** [V1](#source-v1)
- **Что известно:** Статья прямо описывает: бумага вставлена, датчик не реагирует — указание на неисправность датчика. Это условие, а не диагноз по одной фразе пользователя.
- **Что можно сделать:** Уточнить индикатор и установленный рулон; передать сведения о возможном датчике специалисту.
- **Что нужно уточнить:** Точная модель; индикатор/текст; правильность установки; началось ли после замены.
- **Пробелы:** Нет процедуры ремонта/калибровки датчика для сотрудника; применимость к конкретной ревизии не размечена.
- **Ожидаемый исход:** Уточнение → справка по условию → специалист.

#### V-03 — Бумага совсем не выходит

- **Случай:** Вики Принт; Бумага совсем не выходит. Условия устанавливаются вопросами ниже.
- **Источник:** [V1](#source-v1), [V2](#source-v2), [V5](#source-v5)
- **Что известно:** Есть ветви: отсутствие бумаги, износ ролика/шестерни, запрет печати, связь и аппаратная неисправность; описан SelfTest.
- **Что можно сделать:** Сначала собрать факт промотки/чека диагностики. При доступе к Fito прочитать параметр «Не печатать документы на чековой ленте»; подключение — по V5. SelfTest описан, но его место в процедуре нужно согласовать без переноса разборки плат.
- **Что нужно уточнить:** Модель; промотка; бумага; чек при включении; связь с Fito; включён ли запрет печати.
- **Пробелы:** Статья смешивает пользовательские и сервисные действия; упомянутой в V1 статьи «Кассовая программа не видит Вики Принт» нет среди 47 активных HTML-документов. Нельзя перескакивать к плате/прошивке или выдавать всю статью сразу.
- **Ожидаемый исход:** Уточнение → применимая проверка; аппаратная ветвь → специалист.

#### V-04 — Выходит пустой чек

- **Случай:** Вики Принт; Выходит пустой чек. Условия устанавливаются вопросами ниже.
- **Источник:** [V1](#source-v1), [V3](#source-v3)
- **Что известно:** Общая статья описывает проблемы механизма; отдельная яркость — только Вики Принт 80 и сервисное вмешательство.
- **Что можно сделать:** Собрать точную модель и характер дефекта; передать результат специалисту. Нельзя считать «не выдает чек диагностики» равнозначным пустому вышедшему чеку.
- **Что нужно уточнить:** Пустой весь рулон или текст бледный; чек диагностики; модель; замена ленты; промотка.
- **Пробелы:** Прямая пользовательская процедура пустой печати и направления ленты в активных статьях не найдена. V3 не универсальна и требует доступа к плате.
- **Ожидаемый исход:** Уточнение → специалист; нет основания советовать случайную настройку.

#### V-05 — Бледная или частичная печать

- **Случай:** Вики Принт; Бледная или частичная печать. Условия устанавливаются вопросами ниже.
- **Источник:** [V3](#source-v3), [V1](#source-v1)
- **Что известно:** V3 относится к Вики Принт 80, рекомендует процедуру при замене механизма: джамперы, прошивка, Set Darkness. V1 описывает наложение печати при проблеме ролика.
- **Что можно сделать:** Показать, что найден сервисный материал, и собрать характер дефекта; не давать кассиру замыкать джамперы.
- **Что нужно уточнить:** Точная модель/ревизия; бледность или полосы/наложение; меняли ли механизм; есть ли SelfTest.
- **Пробелы:** Нет универсальной настройки яркости для всех Вики; архив/инструменты и визуальная схема нужны специалисту.
- **Ожидаемый исход:** Уточнение → справка о сервисной процедуре → специалист.

#### V-06 — Бумага замялась

- **Случай:** Вики Принт; Бумага замялась. Условия устанавливаются вопросами ниже.

- **Что нужно уточнить:** Замята лента или заклинил нож; модель и год; повторяемость; требуется ли разборка.
- **Пробелы:** Самостоятельное устранение замятия в активном тексте не найдено. Отключение отрезчика — изменение оборудования с разборкой, не эквивалент устранению замятия.

#### V-07 — Не печатается QR-код

- **Что нужно уточнить:** Точная модель/версия; QR отсутствует или не читается; есть ли нужный файл и доступ к Fito.
- **Пробелы:** В индексированном тексте нет имени/содержимого/ссылки на файл макроса. Ссылка могла быть потеряна при извлечении HTML: отсутствие в тексте не доказывает отсутствия на сайте.

#### V-08 — Касса не отвечает программе

- **Случай:** Вики Принт; Касса не отвечает программе. Условия устанавливаются вопросами ниже.
- **Источник:** [V5](#source-v5), [V6](#source-v6), [V2](#source-v2)

- **Что можно сделать:** Уточнить тип подключения; закрыть кассовую программу перед Fito; проверить фактический порт: VikiClient для Viki Driver, конфигурация ComProxy или диспетчер устройств для прямого COM.
- **Что нужно уточнить:** ОС/кассовое ПО; тип службы; физический интерфейс; ошибка; фактический порт; одно или несколько устройств.
- **Пробелы:** 50003 — значение по умолчанию, не гарантированное; конкретная кассовая программа может требовать отдельной настройки. Переустановка/прошивка не первый универсальный шаг.
- **Ожидаемый исход:** Уточнение → инструкция выбранного подключения; аппаратные/сервисные работы → специалист.

#### V-09 — Конкретный код или текст ошибки

- **Что нужно уточнить:** Полный текст; операция; модель/версия; статус смены; программа; уже выполненные действия.
